Автоматическая аналитика дефицитов по результатам внешних оценочных процедурv1

Свод дефицитов учеников по темам/разделам на основе выгрузок ВПР и протоколов ОГЭ. Отдельный инструмент, не связан с аналитикой дефицитов педагогов. ВПР работает по любому предмету и классу; из ОГЭ пока полностью поддержана математика — остальные предметы подключаются по мере поступления образцов реальных файлов.

1

Файлы ВПР

Один или несколько xlsx-файлов выгрузки ВПР — многолистовой файл с листами «… Достижение планируемых результатов» по каждому предмету. Данные читаются на уровне региона / муниципалитета / школы напрямую из готовых процентов выполнения — пересчитывать средние не нужно.

2

Файлы ОГЭ (протоколы по школам)

Каждый файл — протокол одной школы по одному предмету (как в примере «02_003601_036.xlsx»). Можно загрузить сразу пачку файлов по разным школам/предметам. В версии 1 полностью разбирается математика; протоколы по остальным предметам будут учтены в списке файлов, но без разбора по темам, пока не появится образец реального файла для проверки формата.

Один или несколько кодов ОО через запятую сузят свод только до этих школ. Пусто — свод строится по всем школам из загруженных файлов.
